| `source` | string | required, indexed | slack, linear, github, code, git or actron |

| `workspaceId` | string | required, indexed | Actron workspace (tenant) the node belongs to; one graph per workspace |
| `ingestedAt` | datetime | required | First written |
| `refreshedAt` | datetime | required, indexed | Last written by ingestion |
| `ontologyVersion` | string | required | Version of the ontology file that defined the node |
| `deleted` | boolean | indexed | Removed or no longer accessible in the source (tombstone) |
